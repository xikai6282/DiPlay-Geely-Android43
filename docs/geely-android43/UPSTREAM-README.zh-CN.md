# DiPlay

为兼容的比亚迪安卓车机提供有线及无线 CarPlay，采用 DiAuto 风格界面。

> 这些项目专注于比亚迪汽车。它们可能在其他品牌上运行，但其他品牌不在支持范围内，也没有增加支持或修复其品牌特定兼容性问题的计划。

[下载与中文网站](https://shihabal3amri.github.io/DiPlay/zh-Hans/) · [完整说明](README.md) · [报告问题](https://github.com/shihabal3amri/DiPlay/issues/new/choose)

0.2.9 为公开预览版，未经 Apple 认证。请安装在车机上，而非 iPhone。无需越狱、转接盒或认证服务器。无线连接支持车载热点或 Wi-Fi Direct（后者需要 Android 10 或更高版本）。

- 可选在中控屏显示仪表地图悬浮卡片：拖动位置、双指缩放、点击打开 CarPlay。仪表地图继续显示；需允许显示在其他应用上层。
- 改进地图缩放：放下双指时不再突然改变尺寸，达到最小或最大尺寸后反向缩放立即响应。
- 可选通过网络 ADB 在仪表盘显示歌曲名、歌手及播放或暂停状态。
- CarPlay 导航小组件显示转向、道路、距离、到达信息及歌曲，适用于支持标准 Android 小组件的启动器。
- Android 11 及以上的兼容启动器可选嵌入实时地图，并提供地图宿主及 DiPlay Home 开发示例。地图共享默认关闭。
- CarPlay 跟随比亚迪昼夜模式；已在全屏建立的连接可在摄像头改变窗口大小时保持连接。如果在狭窄的摄像头窗口中连接，窗口扩大后需要重新连接一次。
- 媒体和导航音频通道支持 0–20，并保留旧版保存的导航选择。
- 应用及网站新增乌克兰语；GPS 在方向未知时不再错误地报告向北。

标准导航小组件需要支持 Android 小组件的启动器；比亚迪内置主页不接受任意小组件。悬浮地图和嵌入地图需要启用“CarPlay 仪表地图”。开发示例仅在源代码中提供。

认证使用从公开固件中提取的实验性配件身份，无法保证未来持续可用。部分车机仍可能卡顿或无法应用图标大小设置。应用界面支持英语、简体中文、阿拉伯语、俄语、乌克兰语和西班牙语。源代码、构建说明及许可证随版本提供。
